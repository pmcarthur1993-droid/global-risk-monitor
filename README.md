# Global Risk Monitor

Primary-source risk monitor for investors: a library of events with historical probabilities, an alert level built from official warnings, and a log of official releases.

Live site: https://pmcarthur1993-droid.github.io/global-risk-monitor/

- `index.html` is the page.
- `data.json` is rewritten after each twice-daily update.

Research and monitoring only. Not investment advice.
